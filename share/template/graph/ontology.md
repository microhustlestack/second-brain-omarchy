# Ontology: Node Types and Verbs

## Node types (nouns)

- Person
- Org
- Project
- Product
- Event
- Place
- Concept
- Asset
- Process

## Allowed verbs (edges)

produces, funds, presents, hosts, sponsors, sells, teaches, partners-with,
features, supports, depends-on, supersedes

Use only these verbs in v1. Add a verb here first, with a one line
definition, before using it in a page. A small, stable verb list is what
keeps the graph queryable.
